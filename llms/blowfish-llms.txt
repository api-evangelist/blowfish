# Blowfish

> Blowfish is a proactive web3 security platform that scans EVM and Solana transactions, EVM messages, and dApp domains before a user signs, returning a recommended action (NONE/WARN/BLOCK), severity-sorted warnings, and human-readable simulation results. It has scanned billions of transactions and protects wallet users across 10+ blockchains. Backed by Paradigm.

## APIs
- [Blowfish Scan API (OpenAPI 3.1)](https://raw.githubusercontent.com/api-evangelist/blowfish/refs/heads/main/openapi/blowfish-v20230308-openapi-original.yml): scan-transaction-evm, scan-message-evm, scan-transactions-solana, scan-domain, download-blocklist. Auth: X-Api-Key header. Hosts: https://api.blowfish.xyz and https://free.api.blowfish.xyz.
